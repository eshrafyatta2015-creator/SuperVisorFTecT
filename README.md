# المشرف الفني / التقنية — بحث ومتابعة بيانات المعلمين

تطبيق ويب (PWA) لبحث ومتابعة بيانات معلمي التكنولوجيا والتطبيقية، مع نسخة App Inventor (`.aia`) لنفس المنطق.

- بحث فوري أثناء الكتابة (بدلاً من القائمة المنسدلة فقط)
- مطابقة جزئية بالاسم / رقم الهوية / المدرسة / التخصص / السكن
- فلاتر (المدرسة، المؤهل العلمي، التخصص) + إبراز الكلمات المطابقة
- تفاصيل كل معلم مع جدول الحصص الأسبوعي
- يعمل دون اتصال بعد أول فتح + أيقونة تثبيت على الهاتف والكمبيوتر

---

## 1) التشغيل المحلي

```bash
node tools/serve.js
# ثم افتح http://127.0.0.1:8127/
```

> أي خادم static يعمل؛ المهم أن يكون `https:` أو `localhost/127.0.0.1` ليعمل Service Worker.

## 2) التثبيت كأيقونة على الجهاز

الرابط المباشر: **`https://eshrafyatta2015-creator.github.io/SuperVisorFTecT/`**

| الجهاز | الطريقة |
|---|---|
| أندرويد (Chrome) | قائمة المتصفح **⋮** ← **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»** |
| آيفون (Safari) | زر المشاركة **⇧** ← **«إضافة إلى الشاشة الرئيسية»** |
| ويندوز (Edge/Chrome) | قائمة المتصفح **⋮** ← **«التطبيقات»** ← **«تثبيت هذا التطبيق كتطبيق»** |
| ماك (Safari) | **ملف** ← **إضافة إلى الشريط الجانبي**، أو زر **⬇ تثبيت** أعلى الصفحة |

بعد التثبيت تظهر الأيقونة في قائمة برامجك / الشاشة الرئيسية ويفتح التطبيق بملء الشاشة ويعمل دون إنترنت.

## 3) طرق البحث

| المثال | النتيجة |
|---|---|
| `853958478` | مطابقة تامة برقم الهوية |
| `٨٥٣٩` | الأرقام العربية تُطبَّع تلقائياً (تعمل مع الإنجليزية والعربية) |
| `اسلام` / `إسلام` | التشكيل والألف والهمزة والتاء المربوطة تُتجاهل |
| `اسلام خليل` | بحث بكلمتين: كل الكلمات يجب أن تظهر معاً |
| `تكنولوجيا` | يطابق التخصص والاسم معاً مع الترتيب حسب الأفضلية |
| `ذكور` | يطابق اسم المدرسة |

الترتيب: التطابق التام ← بداية الكلمة ← داخل الكلمة ← جزء من الحقل، مع وزن حسب أهمية الحقل (الاسم ثم الهوية ثم المدرسة…).

## 4) ملفات App Inventor (`.aia`)

| الملف | الوصف |
|---|---|
| `app-inventor/SuperVisorFTecT.aia` | النسخة بعد تطوير البحث (SearchBox + زر «بحث» + مطابقة جزئية) |
| `app-inventor/SuperVisorFTecT_v1_backup.aia` | النسخة الأصلية قبل التعديل |

للاستيراد: افتح [App Inventor](https://ai2.appinventor.mit.edu/) ← **Projects** ← **Import project (.aia)**.

### إعادة بناء ملف `.aia` بعد أي تعديل

```bash
# 1) استخراج النسخة الأصلية
# 2) تشغيل سكربت تعديل الكتل
node tools/patch_supervisor_search.js
# 3) إعادة البناء
py tools/pack_aia.py <مجلد_المستخرج> app-inventor/SuperVisorFTecT.aia
```

`tools/_parse_bky.js` محلل يطبع منطق الكتل بصيغة مقروءة لفحص أي تعديل.

## 5) البيانات

المصدر: جدول Google Sheets (تصدير CSV مباشر مع `Access-Control-Allow-Origin: *`).

- يُجلب حيّاً عند كل فتح (`مباشر`)
- يُحفظ نسخة في `localStorage` + نسخة ثابتة في `data/teachers.csv`
- عند انقطاع الاتصال يُستخدم آخر نسخة محفوظة تلقائياً
